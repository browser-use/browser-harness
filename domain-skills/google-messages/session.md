# Google Messages Web session reuse

Conversations URL: `https://messages.google.com/web/conversations`.

Reuse a paired tab rather than opening duplicates. With Messages active in another tab or browser, this page can show **Use Google Messages for web here?** and **Use here**. The conversation list may remain visible behind this blocking overlay; visible snippets alone do not prove this tab is active. Selecting Use here activates the selected web instance. Preserve the paired tab and avoid signing out/unpairing devices during ordinary checks.

The Google account button exposes the signed-in account identity. Verify it against the requested browser/account rather than inferring it from the tab title. A pairing or offline screen requires the user to restore the phone connection.

For authorized verification-code tasks, inspect only the relevant current conversation and match service/sender plus request time. The conversation list can contain stale codes. Avoid capturing or dumping the whole inbox, storing codes in notes, or echoing codes in status replies. Browser-session persistence does not guarantee phone pairing remains valid indefinitely.
