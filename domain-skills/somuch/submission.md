# SoMuch directory submissions

- Submission route: `https://www.somuch.com/submit-links/`.
- A submission receipt can require email verification before editorial review.
- Verification links use `/verify-link/<link-id>/<user-id>`; treat those identifiers as private task state rather than including them in shared notes.
- The verification page can retain a stale header after checking its verification box and saving. Reload and look for **YOUR LINK HAS BEEN VERIFIED** before reporting success.
- Verification establishes eligibility for review, not publication. Retain the receipt and check the eventual directory entry separately.
