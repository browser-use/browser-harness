# Huzzler free submissions

- `/submit-product` displays the plan comparison before listing. Inspect the current free-plan conditions as well as price.
- The free route can require an embedded platform badge, carry a long queue, and explicitly omit Google indexing. Paid plans can remove these conditions.
- A zero-dollar price does not make the free route an immediately indexable backlink. Do not edit the submitter website to install reciprocal badges without authorization for that website change.
