# Launch Llama Tools submissions

- Start at `https://tools.launchllama.co/submit`.
- Account creation, product details, plan selection, and the final submission gate are separate states. Do not count a filled form as a submitted listing.
- A free plan can be offered on more than one consecutive page; selecting it once does not finish the flow.
- The final free gate can require upvoting other tools and publishing a star rating with minimum-length feedback on another product. Inspect the current requirements before describing the free route as unconditional.
- Other-product votes and testimonials need their own factual basis and authorization. Do not fabricate reviews to finish a directory submission.
- Browser-side file uploads resolve paths on the machine running Chrome. With a WSL controller attached to Windows Chrome, pass an existing Windows path to `DOM.setFileInputFiles`, not the WSL path.
